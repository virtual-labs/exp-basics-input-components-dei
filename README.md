### About the Experiment 

This experiment focuses on simulating the interfacing of fundamental input components with the Arduino microcontroller in an IoT environment.  
It demonstrates how digital devices such as pushbuttons and slider switches generate discrete logic signals.  
Analog devices like potentiometers and photoresistors produce variable voltage signals that are read using the Arduino’s ADC.  
Students learn the concepts of signal acquisition, voltage division, and real-time data monitoring through embedded programming.  
The simulation provides practical understanding of hardware–software interaction without requiring physical components.
